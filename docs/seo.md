# SEO and discovery contract — v0.2.2

- One canonical URL per localized public page.
- Reciprocal SK/EN/DE hreflang plus x-default.
- `sitemap.xml` is the complete URL inventory; `feed.xml` is the recent-update discovery feed.
- `OAI-SearchBot` is allowed; `GPTBot` is blocked by policy.
- Stable Person URIs and external `sameAs` links are preferred over extra keyword metadata.
- Homepage is a neutral two-person identity landing page.
- Profile metadata describes the person positively and does not use namesake-negation as a ranking tactic.
