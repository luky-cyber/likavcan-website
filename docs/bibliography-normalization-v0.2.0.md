# Bibliography normalization — v0.2.0 RC2

Normalized 2026-08-30.

Rules:
- SK/EN/DE use one canonical set of bibliographic facts.
- DOI is displayed only on the exact work to which it resolves.
- Conference versions are distinct records from later journal articles, even when titles overlap.
- Structured data is not expanded beyond verified records merely for SEO.
- Source fidelity wins over silent title correction (for example the STU catalogue title “Možnosti skenovanie valcových súčiastok optickým 3D skenerom”).

Canonical machine-readable master: `docs/bibliography-master-v0.2.0.json`.
